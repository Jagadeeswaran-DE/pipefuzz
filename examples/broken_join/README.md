# Broken join example

`transform` joins orders directly to a customer dimension that is assumed to be unique. PipeFuzz's `join_amplification` strategy generates a matching fact key and at least two dimension rows with that key. The real Spark aggregation therefore repeats the fact amount, and `no_join_amplification` reports the minimized generated input.

```bash
pipefuzz test examples/broken_join/pipeline.py::transform \
  --config examples/broken_join/pipefuzz.yaml
```

The keys, amount, country, row counts, and minimal failure are generated by Hypothesis; the engine contains no copy of a predetermined example.
